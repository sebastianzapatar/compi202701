Semana 01 · Bloque I: Dominando Go

Fundamentos de Go para Compiladores

Antes de construir el intérprete de Monkey, aprenderemos las piezas esenciales de Go: su modelo de paquetes, tipos de bajo nivel, control de flujo, slices y maps, todo orientado directamente a lo que necesitaremos en el Lexer, Parser y Evaluador.

Duración: Semana 1 (2 sesiones) Referencia: Intro de Writing An Interpreter In Go Objetivo: Primer programa y estructuras base en Go

1. ¿Por qué usar Go para escribir un Intérprete?

En la introducción del libro, Thorsten Ball explica por qué eligió Go en lugar de C, Java o Python. La razón principal es su simplicidad deliberada:

Ventajas para Aprender

  • Cero dependencias externas: Solo usamos la biblioteca estándar de Go.
  • Testing integrado: El comando go test viene listo de fábrica.
  • Formato universal: gofmt elimina discusiones de estilo.
  • Sin "magia": No hay metaprogramación oculta ni jerarquías complejas de herencia.

Transferible a Otros Lenguajes

El código Go que escribiremos se traduce casi 1 a 1 a lenguajes de sistemas como C, C++ y Rust, o lenguajes modernos como TypeScript y Java.

Además, Go compila a binario nativo en milisegundos y cuenta con Garbage Collector, lo que nos simplificará la vida en la Semana 7.

Enfoque de estas 2 semanas: No estudiaremos concurrencia avanzada ni desarrollo web en Go; nos concentraremos al 100% en las herramientas exactas que hacen brillar un intérprete.

2. Instalación, Módulos y Paquetes

Todo proyecto moderno en Go se organiza alrededor de un módulo (archivo go.mod) y uno o más paquetes (carpetas).

Terminal · Crear proyecto
# 1. Verificar versión de Go (>= 1.20 recomendado)
go version

# 2. Crear carpeta e inicializar módulo
mkdir monkey && cd monkey
go mod init monkey

# 3. Ejecutar el programa principal
go run main.go
main.go
package main

import "fmt"

func main() {
    fmt.Println("¡Hola, Monkey!")
}

Regla de Oro de Visibilidad en Go (¡Sin public ni private!)

  • Empieza con MAYÚSCULA (ej. NextToken(), Token): es exportado (público), visible desde otros paquetes.
  • Empieza con minúscula (ej. readChar(), isLetter()): es privado al paquete.

3. Variables, Constantes y Tipos Básicos

Go es un lenguaje estáticamente tipado: toda variable tiene un tipo conocido en tiempo de compilación, pero la inferencia con := lo hace muy ágil.

variables.go
// Declaración explícita (toma su "zero value")
var edad int64        // 0
var activo bool       // false
var nombre string     // ""
var ch byte           // 0 (NUL en ASCII)

// Declaración corta con inferencia (solo dentro de funciones)
x := 42               // int
literal := "let"      // string

// Constantes (muy usadas para TokenType)
const (
    LET   = "LET"
    IDENT = "IDENT"
    INT   = "INT"
)

Tipos que más usaremos en Monkey

TipoUso en el Intérprete
stringCódigo fuente, literales de tokens, errores
byteCarácter actual (l.ch) en el Lexer (alias de uint8)
intÍndices de posición (position, readPosition)
int64Valores enteros de Monkey (object.Integer)
boolCondiciones y booleanos de Monkey
Ojo en Go: No existen variables sin usar ni imports sin usar. Si declaras una variable y no la lees, el compilador no compila. Usa el identificador blanco _ cuando quieras ignorar un valor intencionalmente.

4. Strings, Bytes y Slicing (El Pan Diario del Lexer)

En la Semana 3 nuestro Lexer leerá el código fuente carácter por carácter. Comprender cómo funcionan string, byte y los recortes (slices) de texto es fundamental.

strings_lexer_preview.go
input := "let x = 5;"

// 1. Acceder por índice devuelve un byte (ASCII)
var ch byte = input[0]        // 'l' (código ASCII 108)
fmt.Println(ch, string(ch))   // 108 l

// 2. Comparar bytes con literales de carácter (comillas simples)
esLetra := 'a' <= ch && ch <= 'z'  // true
esDigito := '0' <= ch && ch <= '9' // false

// 3. Slicing [inicio:fin] — incluye inicio, EXCLUYE fin
palabra := input[0:3]         // "let"
resto   := input[4:]          // "x = 5;"

// 4. Longitud en bytes
fmt.Println(len(input))       // 10
Conexión directa con el libro: En Monkey, el método readIdentifier() guarda la posición inicial, avanza mientras isLetter(l.ch) sea verdadero y al final simplemente retorna l.input[position:l.position]. ¡Sin copiar caracteres uno a uno!

5. Control de Flujo: if, for y switch

Go simplifica el control de flujo: sin paréntesis obligatorios alrededor de condiciones, llaves { } siempre obligatorias, y solo existe una palabra reservada para ciclos: for.

if_y_for.go
// if con declaración previa (¡muy idiomático en Go!)
if val, ok := keywords[ident]; ok {
    return val
}

// for clásico (3 partes)
for i := 0; i < 5; i++ {
    fmt.Println(i)
}

// for como "while"
for isLetter(ch) {
    pos++
}

// for infinito (así funciona nuestro REPL)
for {
    // leer línea, evaluar, imprimir...
    break
}
switch.go
// switch NO requiere "break" (no hace fall-through)
switch ch {
case '=':
    fmt.Println("Asignación")
case '+', '-':
    fmt.Println("Suma o resta")
case 0:
    fmt.Println("Fin de archivo (EOF)")
default:
    fmt.Println("Otro carácter")
}

// switch sin expresión (reemplaza cadenas if/else if)
switch {
case n < 0:
    fmt.Println("Negativo")
case n == 0:
    fmt.Println("Cero")
default:
    fmt.Println("Positivo")
}

6. Funciones, Múltiples Retornos y Errores

En Go no existen excepciones (try / catch). En su lugar, las funciones pueden devolver múltiples valores, donde el último suele ser un error.

funciones.go
package main

import (
    "fmt"
    "strconv"
)

// Parámetros del mismo tipo pueden compartir declaración
func sumar(a, b int64) int64 {
    return a + b
}

// Retorno múltiple: resultado + error
func parsearEntero(literal string) (int64, error) {
    valor, err := strconv.ParseInt(literal, 0, 64)
    if err != nil {
        return 0, fmt.Errorf("no se pudo parsear %q como entero", literal)
    }
    return valor, nil
}
Verás esto en el Parser (Semana 5): Exactamente así usaremos strconv.ParseInt(p.curToken.Literal, 0, 64) para convertir el texto "42" en un número real int64(42) al construir un ast.IntegerLiteral.

7. Slices: Listas Dinámicas en Go

Aunque Go tiene arreglos de tamaño fijo ([3]int), en la práctica casi siempre usamos slices ([]T), que crecen dinámicamente con append.

slices.go
// Crear slices
var errores []string                // nil slice (len 0)
numeros := []int{10, 20, 30}        // literal
buffer := make([]string, 0, 16)     // len 0, cap 16

// Agregar elementos (SIEMPRE reasignar)
errores = append(errores, "falta ';'")
errores = append(errores, "token inesperado")

// Recorrer con range (índice y valor)
for i, err := range errores {
    fmt.Printf("[%d] %s\n", i, err)
}

// Si solo necesitas el valor:
for _, num := range numeros {
    fmt.Println(num)
}

¿Dónde usaremos Slices en Monkey?

  • Program.Statements: lista de sentencias del programa ([]ast.Statement).
  • Parser.errors: lista acumulada de errores de sintaxis ([]string).
  • Function.Parameters: lista de parámetros de una función.
  • Array.Elements: elementos de un arreglo en Monkey ([]object.Object).

8. Maps: Diccionarios Clave → Valor

Un map[K]V es la tabla hash nativa de Go. Es indispensable para reconocer palabras reservadas, registrar funciones del Pratt Parser y almacenar variables en el Environment.

maps.go
// Literal de map (palabras reservadas de Monkey)
var keywords = map[string]string{
    "fn":     "FUNCTION",
    "let":    "LET",
    "true":   "TRUE",
    "false":  "FALSE",
    "if":     "IF",
    "else":   "ELSE",
    "return": "RETURN",
}

// Inicializar un map vacío listo para escribir
env := make(map[string]int64)
env["x"] = 5

// Patrón "comma ok" para distinguir clave inexistente
if tok, ok := keywords["let"]; ok {
    fmt.Println("Es keyword:", tok)
} else {
    fmt.Println("Es identificador")
}

Trampa clásica de principiante

Leer de un map sin inicializar devuelve el zero value, pero escribir en un map que es nil causa panic.

var m map[string]int // ¡nil!
// m["a"] = 1        // ¡PANIC!

m = make(map[string]int) // Correcto
m["a"] = 1

9. Taller Práctico — Semana 1

Reto: Mini Escáner de Palabras Clave en Go

Crea un módulo Go (go mod init taller01) con un archivo main.go que reciba una cadena de texto estilo código fuente:

codigo := "let x = 10; if (x > 5) { return true; }"
  1. Escribe una función extraerPalabras(input string) []string que recorra el string carácter por carácter usando índices y isLetter(ch byte) bool, extrayendo palabras con slicing input[inicio:fin].
  2. Usa un map[string]string de palabras reservadas (let, if, else, return, true, false, fn).
  3. Clasifica cada palabra extraída como KEYWORD o IDENT y cuenta cuántas veces aparece cada tipo usando otro map[string]int.
  4. Bonus: Agrega también una función extraerNumeros(input string) []int64 usando strconv.ParseInt.
