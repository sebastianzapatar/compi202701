Parte C · Programación en Go40 pts

Implementa en tu repositorio. Cada función debe tener su prueba table-driven.

10

String() para los nodos

14 pts

Agrega String() string a la interfaz Node e impleméntalo en Program, LetStatement, ReturnStatement e Identifier. Haz pasar la prueba del libro:

program := &Program{
    Statements: []Statement{
        &LetStatement{
            Token: token.Token{Type: token.LET, Literal: "let"},
            Name:  &Identifier{Token: token.Token{Type: token.IDENT, Literal: "myVar"}, Value: "myVar"},
            Value: &Identifier{Token: token.Token{Type: token.IDENT, Literal: "anotherVar"}, Value: "anotherVar"},
        },
    },
}
if program.String() != "let myVar = anotherVar;" { t.Errorf(...) }
